# 🖌️ CreatedForYou

> **Personalize. Crie. Torne único.**

O **CreatedForYou** é um site desenvolvido para apresentar e solicitar produtos personalizados, permitindo que o usuário conheça o catálogo disponível e
monte seu próprio pedido de personalização.

O projeto foi desenvolvido utilizando **HTML, CSS, JavaScript e Bootstrap**, com foco em uma interface simples, responsiva e intuitiva.

---

## ✨ Sobre o Projeto

A ideia do **CreatedForYou** é oferecer uma experiência simples para quem deseja transformar objetos comuns em produtos personalizados.

O usuário pode:

* 🛍️ Visualizar produtos disponíveis;
* 🔎 Ver detalhes de cada produto;
* 💰 Consultar preços;
* 🎨 Escolher um objeto para personalizar;
* ✍️ Adicionar uma mensagem ou detalhes do pedido;
* 📩 Solicitar seu produto personalizado.

---

## 🚀 Funcionalidades

### 📦 Catálogo de produtos

Os produtos são cadastrados através de objetos JavaScript e apresentados automaticamente na página.

Cada produto possui:

* Nome;
* Preço;
* Categoria;
* Descrição;
* Imagem.

---

### 🔎 Detalhes do produto

Ao clicar em **"Ver detalhes"**, é aberto um modal do Bootstrap contendo:

* Nome do produto;
* Categoria;
* Preço;
* Descrição;
* Botões para fechar ou realizar o pedido.

---

### 🎨 Monte o Seu

A seção **"Monte o Seu"** permite que o usuário informe os dados necessários para criar uma solicitação personalizada.

O formulário possui:

* Nome;
* E-mail;
* Imagem da personalização;
* Escolha do objeto;
* Mensagem com detalhes do pedido.

## 📱 Responsividade

O projeto utiliza o sistema de grid do **Bootstrap**, permitindo que o catálogo se adapte a diferentes tamanhos de tela.

### Desktop

São exibidos até **3 produtos por linha**.

### Tablet

São exibidos até **2 produtos por linha**.

### Celular

Os produtos são apresentados em **uma coluna**, facilitando a navegação em telas menores.

---

## 🎨 Design

A interface utiliza uma combinação de:

* Azul como cor principal;
* Componentes do Bootstrap;
* Cards para apresentação dos produtos;
* Modais para informações detalhadas;
* Formulários para personalização;
* Layout responsivo.

O objetivo é manter uma aparência moderna e simples, deixando os produtos como destaque principal da página.
